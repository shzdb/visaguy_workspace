# Agent Resources

This directory contains canonical resources for agents working on the VisaGuy workspace.

## Rules

- `rules/project-rules.md` — mandatory boundaries, authority model, verification labels, and safety rules.

## Skills

- `skills/implementation-audit.md` — how to audit implementation evidence against workspace claims without writing code.

## Templates

- `templates/feature.md` — create a new feature document.
- `templates/task.md` — create a new implementation task.
- `templates/decision.md` — create a new architecture decision record.
- `templates/completion-report.md` — record completion evidence for a task or feature.

## How to use

1. Read `rules/project-rules.md` first.
2. Read the relevant skill before beginning a specialized activity.
3. Copy the relevant template into the appropriate lifecycle folder (`features/`, `tasks/`, `decisions/`, or the task completion notes) and fill in every section.
4. Keep folder status and document metadata `status` aligned.
