## Design notes and deviations
- Roles: read from fixtures/custom_docperm.json (permlevel 0, read=1). Passport Extraction: System Manager, Passport Extractor User, Operations Associate, Operations Team Lead. Visa Tracking Application: 19 roles (the tracking read roles plus Visa Tracker Manager/Operator and System Manager). A test asserts both lists equal the DocPerm rows.
- Day of an extraction (daily summary): `processing_completed_on`; unfinished ones (Queued/Processing, no completion date) are counted on `creation`. Two get_list reads, grouped in Python (avoided SQL date functions in get_list fields, whose acceptance in v15 I did not verify). Added an "Other" column (Rejected/Duplicate/Superseded) so Total equals the sum of the columns. Summary shows today's totals independent of the date filters (extra two reads).
- Failed report: date filter is on `processing_completed_on`. Error code filter is a Data field; the value "Unknown" matches blank codes. "Process File" = oldest Process File whose `file_collection` or `custom_lead_file_collection` is the extraction's source collection (two batched reads). "Retried" = a newer extraction exists for the same source doctype, document and row (one batched read).
- Applications report: origin is computed in Python from application `creation` vs Process File `creation` (one batched read of Process File), per the approved definition; the origin filter is applied after the read.
- Default range is the last 30 days including today (today - 29), in both Python and JS.
- Number Card "today" filters: `dynamic_filters_json` = `[[doctype, field, "Between", "[frappe.datetime.get_today(), frappe.datetime.get_today()]"]]`. Between on a Datetime field expands to start and end of day (Frappe `get_between_date_filter`). Frappe's JS evals `f[3]`, so an array literal string works. Cards are `is_standard 0`, `is_public 1`.
- Failed Extractions by Reason (Group By): blank error codes are excluded by Frappe's group-by (`ignore_ifnull`), so they do not show as "Unknown" in the chart; the report does show them. "Last 30 days" is a dynamic filter `processing_completed_on >= add_days(today, -29)`.
- Workspace: existing header and five shortcuts kept; added headers Today / Passport extraction / Tracking applications, five number cards (col 3 each, one row of 12 plus a wrap: 5 x 3 = 15, so the fifth card wraps to a second row), charts as specified, and two Card Break link cards ("Passport Extraction Reports", "Tracking Application Reports"). The Tracking Application card links report 3 and Visa Tracking Coverage. Number Card col width of 3 gives 4 per row; the fifth wraps. This is a deviation from "one row": use col 2 if the owner wants a single row (Frappe's grid is 12 columns, so 5 cards cannot fit evenly).
- Workspace `modified` set to 2026-10-06 so the fixture import takes the new version.
